# Task 3: Native iOS libssh2 module (password auth) with streaming output

## Summary
Created RNSSHModule native module using libssh2 C API directly for iOS.

## Files Created/Modified

### TmuxMobile/ios/Podfile
Changed to use NMSSH pod which bundles libssh2:
```ruby
pod 'NMSSH', :git => 'https://github.com/aanah0/NMSSH.git'
```
Note: libssh2-iosx pod has build script issues (OpenSSL/CMake failures).
NMSSH provides working libssh2 library; our code uses libssh2 C API directly.

### TmuxMobile/ios/TmuxMobile/RNSSHModule.h
React Native event emitter header:
```objc
@interface RNSSHModule : RCTEventEmitter <RCTBridgeModule>
@end
```

### TmuxMobile/ios/TmuxMobile/RNSSHModule.mm
Full native module implementation using libssh2 C API:
- `#include <libssh2/libssh2.h>` - Uses libssh2 C library directly
- `LIBSSH2_SESSION *session` - libssh2 session handle
- `LIBSSH2_CHANNEL *channel` - libssh2 channel handle
- `libssh2_socket_t sock` - Socket handle
- `libssh2_init(0)` / `libssh2_exit()` - Library lifecycle
- `libssh2_session_init()` - Create session
- `libssh2_session_handshake()` - SSH handshake
- `libssh2_userauth_password()` - Password authentication
- `libssh2_channel_open_session()` - Open channel
- `libssh2_channel_request_pty()` - Request PTY
- `libssh2_channel_shell()` - Start shell
- `libssh2_channel_read()` - Read data (in background loop)
- `libssh2_channel_write()` - Write data
- `libssh2_channel_request_pty_size()` - Resize terminal

## Exported Methods
- `connect(host, port, username, password)` - Promise-based SSH connection
- `disconnect()` - Clean shutdown
- `startTmuxControlMode(sessionName, windowIndex)` - Start tmux -CC
- `startCommand(command)` - Generic command execution
- `write(data)` - Send data to channel
- `resize(cols, rows)` - PTY resize

## Events Emitted (base64 encoded data)
- `onData: { data: "<base64>" }` - Streamed output
- `onError: { error: "<message>" }`
- `onDisconnect: { reason: "<message>" }`

## Key Implementation Details

### Background Thread Read Loop
```objc
- (void)startReadLoop {
    dispatch_async(_sshQueue, ^{
        char buffer[4096];
        while (!self.shouldStopReading && self.channel) {
            ssize_t bytesRead = libssh2_channel_read(self.channel, buffer, sizeof(buffer));
            if (bytesRead > 0) {
                NSData *data = [NSData dataWithBytes:buffer length:bytesRead];
                dispatch_async(dispatch_get_main_queue(), ^{
                    [self emitData:data];
                });
            } else if (bytesRead == LIBSSH2_ERROR_EAGAIN) {
                usleep(10000);
            }
            ...
        }
    });
}
```

### Base64 Event Emission
```objc
- (void)emitData:(NSData *)data {
    if (!_hasListeners) return;
    NSString *base64 = [data base64EncodedStringWithOptions:0];
    [self sendEventWithName:@"onData" body:@{@"data": base64}];
}
```

## Security
- Password never logged
- All SSH operations on background dispatch queue (com.tmuxmobile.ssh)
- Main thread not blocked
- Proper cleanup in disconnectInternal
